# IOTech Site

Static HTML, CSS, and JavaScript website for the IOTECH Club.

## Directory Structure

```text
IOTech-Site-main/
|-- index.html                 # Main single-page website
|-- README.md                  # Project notes and structure
|-- assets/
|   |-- images/                # Site images
|   |   `-- members/           # Team/member photos
|   `-- images-placeholder.txt # Original placeholder file kept safely
|-- css/
|   |-- style.css              # Active site styling
|   `-- legacy-styles.css      # Older backup stylesheet
|-- js/
|   `-- script.js              # Extra site scripts/data registry
`-- pages/
    |-- design.html            # Department/page section source
    |-- documentation.html
    |-- events.html
    |-- management.html
    |-- media-gallery.html
    `-- technical-projects.html
```

Open `index.html` in a browser to run the site.
